# 13日の金曜日ガチャ

レトロホラー調のスロットで「誰に」「何をされて」「どうなる」を決めるブラウザゲームです。

## 起動

`index.html` をブラウザで開いてください。ビルド・npm install・外部ライブラリ・外部アセットは不要です。

HTTPで確認する場合は、このフォルダで `python -m http.server 8133 --bind 127.0.0.1` を実行し、`http://127.0.0.1:8133` を開きます。

## 実装内容

- 45ms間隔の導入テキスト。クリック／タップで全文表示し、「次へ」で開始。
- 指定の10 × 15 × 5候補からMath.randomで独立した均等抽選。開始時点で全結果を確定。
- 0.8秒、1.6秒、2.6秒で順に停止、2.9秒で結果表示。2つ目の停止音の後に静かな間。
- 減速・停止の跳ね返り・赤い発光、スキップ、多重抽選防止、再プレイ時のタイマー解除。
- 死亡・老衰・成仏・爆散・生存の5種類の演出。粒子は最大32個。
- Web Audio APIによる生成音、音声切替、自動再生制限への対応、ページ非表示時の消音。
- Canvasによる1200 × 675pxのPNG保存。直接保存できない環境向けに保存用画像も表示。
- Xの投稿作成画面に結果・ハッシュタグ・現在のページURLを渡す。画像の添付は手動。投稿文のコピー機能付き。
- PC／スマートフォンの横並びスロット、標準buttonのキーボード操作、フォーカス表示、動きを減らす設定に対応。

音声は初回の操作後に有効になります。音声非対応でもゲームは進みます。ローカルファイルで開いたときは共有文にファイルパスを含めません。

## ファイル

- `index.html`：画面と操作ボタン
- `style.css`：レスポンシブレイアウトと演出
- `script.js`：状態管理、抽選、音声、画像保存、共有
- `test.cjs`：依存ライブラリ不要のロジック検証（開発用）

## GitHub Pages

公開用リポジトリの同じフォルダに `index.html`、`style.css`、`script.js` を配置し、そのフォルダをGitHub Pagesの公開元に設定してください。相対パスのため、リポジトリ名付きのURLでも動作します。この作業ではリポジトリ作成・公開は行っていません。

## 検証

Node.jsがある環境で `node --check script.js` と `node test.cjs` を実行できます。

自動テストは簡易DOMと仮想タイマーで750通りの到達可能性、連打防止、停止時刻、4つのタイミングでのスキップ、再プレイ時の解除、5種の結果、共有URLを検証します。実ブラウザのレイアウトや音声・ダウンロードの検証は含みません。

制作環境ではアプリ内ブラウザからローカルサーバーへの接続がタイムアウトしたため、実画面・実音声・端末別保存動作は未確認です。
